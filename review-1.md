# ¿Qué es mi producto y para qué sirve?

Mi producto es un servidor web sencillo y eficiente que permite consultar una lista de tareas a través de internet. 

Funciona como la base de una aplicación de organización personal o empresarial, donde los usuarios pueden visualizar tareas pendientes o completadas. Este tipo de sistema puede integrarse fácilmente con aplicaciones móviles, páginas web o plataformas internas de una empresa.

Su objetivo principal es ofrecer una estructura clara y organizada para gestionar tareas, facilitando el seguimiento de actividades diarias.

---

# ¿Cuáles son las funcionalidades más importantes y por qué los usuarios las usarían?

## 1️Consulta de tareas
El sistema permite obtener una lista de tareas en formato estructurado.  
Esto es útil porque:

- Permite visualizar actividades pendientes.
- Facilita el seguimiento del progreso.
- Puede integrarse con otras aplicaciones digitales.

## Información clara y organizada
Cada tarea contiene:

- Un identificador único.
- Un estado (completada o pendiente).
- Una descripción clara de la actividad.

Esto ayuda a mantener orden y trazabilidad en las actividades.

## Base escalable
Aunque actualmente muestra una lista básica, el sistema está preparado para crecer y convertirse en una aplicación completa de gestión de tareas.

---

# ¿Qué tecnologías usé y por qué?

## Node.js
Se utilizó como entorno de ejecución porque permite crear aplicaciones rápidas y eficientes del lado del servidor.

## Express
Express es una herramienta que facilita la creación de servidores web de forma sencilla y organizada.  
Fue elegida porque:

- Es ligera y rápida.
- Permite estructurar fácilmente rutas y respuestas.
- Es ampliamente utilizada en la industria.

## JSON
Se usa como formato de respuesta porque es el estándar moderno para intercambiar información entre sistemas y aplicaciones.
